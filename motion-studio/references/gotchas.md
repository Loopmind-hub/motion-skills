# Gotchas — each one cost a round in a real build

| # | Symptom | Cause | Fix |
|---|---|---|---|
| 1 | Whole first half washed out, muddy beige | A `fromTo` flash/overlay (`{opacity:.32}→{0}`) renders its FROM state at build and holds it until its start time | `immediateRender: false` on any fromTo whose from-state must not show before it starts. Audit every `fromTo` that starts after 0 |
| 2 | Hook sounds weak / quiet | Normalising the whole mix to −14 LUFS lets the drop dominate; the hook bar sat 6 LU under | Read `bar_lufs`; push hook voice/impacts; score.py warns |
| 3 | Voice chops land early/late | Whisper word timestamps were 1.1–1.7 s off on phone clips | Measure onsets from RMS of the wav; Whisper only for WHAT was said |
| 4 | Text jitters during a tracking animation | `letterSpacing` tween snaps to device pixels | Per-glyph spans, animate `x` |
| 5 | Two headlines readable at once mid-swap | Exit and entry overlapped | Exit fast first, enter 0.1–0.2 s later |
| 6 | `check` shows dozens of overlap errors on hidden text | Masked/offscreen text still counts as present | Give each headline/caption `class="clip"` + `data-start`/`data-duration` for its window |
| 7 | Captions invisible over full-screen video | Stacking: cards had z-index, captions `auto` | Explicit z-index for every text layer |
| 8 | Card and tilted 3D phone don't line up | Card isn't a DOM child of the phone, so it can't inherit the 3D transform | Keep the phone 2D, or make the media a child of the phone from the start. Never reparent mid-timeline |
| 9 | `ffmpeg … drawtext` fails | This ffmpeg build has no drawtext/freetype | Label frames with Pillow (review.py) or `magick -font /System/Library/Fonts/Supplemental/Arial.ttf` |
| 10 | Motion-blurred element flashes unclipped copies | The blur component clones the subtree; clip-path/video inside behave badly | Blur only plain text/solid shapes; never video cards or clip-path reveals |
| 11 | `gsap_css_transform_conflict` | CSS `transform` initial state on something GSAP also tweens | Put the initial state in `fromTo`, not CSS. Center with left/width/text-align, not translate(-50%) |
| 12 | `npx hyperframes skills update` / `npx skills add` blocked | It writes 20+ skills into `~/.claude/skills` (global layer) | Don't install them. Read them from `~/tools/hyperframes/skills/` and scaffold with `HYPERFRAMES_SKIP_SKILLS=1` |
| 13 | Blank card mid-video | A `<video>` ran out of source media before its clip window ended | `media-start + data-duration ≤ source length`; chain a second `<video>` for longer windows |
| 15 | An element jumps across the frame during a shake/wiggle | GSAP `keyframes: {x: [...]}` values are ABSOLUTE, but the element already sat at a non-zero x | Offset every keyframe by the element's resting x (Reely v3, take-4 head-shake) |
| 16 | Frames look great one by one, yet the render feels slow in places | Small UI events (thin lines, 30px text) barely move pixels; real holds hide between beats | Trust `review.py`: 22/30 beats + 2.3 s dead time on Reely v2 despite clean sheets. Make beat events bigger (row flash + camera punch), fill holds |
| 17 | A small black diamond floats mid-frame for seconds | A stroke "undrawn" with `strokeDashoffset = length` still paints its **square/round linecap** at the dash end — rotated along the path, it reads as a diamond (Servi v1) | Also tween `opacity: 0` once undrawn; `tl.set(opacity:1)` right before it redraws. **A `clip` window on the `<svg>` does NOT hide it either** (Servi demo, 3-oct-2026: a «growth curve» end-cap sat as a blue dot for 70 s) — start the path at `opacity: 0` in its style |
| 18 | An element returns to the wrong place at the end (the logo reassembled crooked, its ink check vanished into the ink square) | In `fromTo`, a property that appears ONLY in the from-vars is never animated — the element kept its earlier offset (Servi v1) | Every property you mean to reset goes in BOTH from and to vars |
| 19 | SVG part scales/moves around the wrong point | `transformOrigin: "16px 15px"` on SVG is relative to the element's bbox, not the viewBox | Use `svgOrigin: "16.3 15.9"` (viewBox units) for SVG children |
| 20 | `check` floods with overlap errors under a card that covers a row | The covered element is still "present" | Once the cover lands, set the covered element's opacity to 0 — it is gone in fact, not just hidden |
| 21 | Final file lands at −14.9 / −15.2 LUFS though the mix was mastered to −14.1 | The HyperFrames audio mux shifts level by up to ~1 dB | `deliver.sh` now runs two-pass loudnorm IN the delivery encode — normalise the final file, never trust upstream |
| 22 | Removing camera punches dropped beat hits 40/40 → 35/40 | The punches were carrying the metric (full-frame change) — i.e. gaming it | Beat hits must come from content; `review.py` camera budget flags punch-heavy cues. Name each miss as a rest or fix it with content |
| 23 | Tweens mysteriously sit at t=0 / captions never disappear | A computed position was NaN (read a neighbour's value before it was assigned) — GSAP silently places a NaN-positioned tween at 0 | Compute in passes; assert `isFinite` on every computed position; debug with headless Chrome + `tl.getChildren()` (startTime/duration) instead of guessing |
| 24 | Sheets look full, render fails the beat gate (web-offer v2: 46/88 beats, 18 s dead) | Small UI inside a device, slow blur reveals, 0.3–0.4 s eases never cross review.py's energy floor | A beat "counts" when roughly **≥2% of the frame changes by ~40+ luma, peaking within 60 ms of the beat**: card background flashes, black→white card flips, callout pills beside the device, entrances with power3.out in ~0.2 s. Still no camera |
| 25 | End card fails dead-time though it has events | A sheen split the hold into two windows ≥0.6 s; only ONE hold is allowed | Keep the hold as one uninterrupted window ≤1.5 s; give every other end-card beat its own event |
| 26 | Big numbers collide with what's under them | Estimated the height of 104 px type + underline; it ran ~30 px deeper | Measure `offsetHeight` at build (fonts loaded) or snapshot that exact beat before placing anything below |
| 27 | A particle/glyph field buries every statement and blows out to white | Additive blending of thousands of light glyphs; text shares their space | A **legibility band**: glyph alpha × `1 − 0.92·exp(−((y−textY)/165)²)` while statements are on screen; paper glyphs at ~50% alpha; skip the near-zero-depth ones in a warp (future-of-AI v1) |
| 28 | review.py calls a constantly-moving scene "dead" | One extreme section (full-frame warp) inflated p90 → floor 1.87 | `adaptive_floor` = min(12% p90, 30% median). For a **continuous-flow** piece (the field never stops) beat hits are naturally low — don't force a per-beat accent to raise them (that's the heartbeat); judge dead time + legibility instead |
| 29 | An element "arrives" then jumps a few px on the last frame of its tween | `springEase` stiffness left 1.5% unsettled at ζ = 1 (0.35% at 0.86); `p >= 1 → 1` snapped it (found building /motion-apple, 2026-09-25) | Fixed in `templates/engine.js` (settles < 0.1% at any ζ; test in engine.test.mjs). **Old projects keep their copied `lib/engine.js`** — re-copy the template if one uses ζ ≥ 0.86 |
| 30 | An SVG part (the Servi bubble) lands permanently offset up-left after a scale-in | `svgOrigin` only in the to-vars: GSAP changes the origin on an already-scaled element and adds a compensating x/y that never goes away (Servi keynote v1, 2026-10-08) | `tl.set(el, {svgOrigin, scale: 0}, 0)` AND `svgOrigin` in both from and to vars |
| 31 | The smear at 60 fps looks half as strong as the 30 fps reference | Shutter angle is per frame: 360° at 60 fps = 16.7 ms, the reference's 360° at 30 fps = 33 ms | To match a 30 fps reference's blur at 60 fps use `shutterAngle: 720` (same exposure, twice the smoothness) |
| 32 | The smear of a moving widget shows the WRONG content (old labels, a giant ring) | The shutter component clones the subtree ONCE at attach (`motion-blur.js` snapshot) and only re-transforms the copies — children that change state later stay frozen in the smear. Cloning a decoy in JS also fails: id-based CSS doesn't follow a renamed copy (Servi keynote v5→v6, 2026-10-08) | `data-hf-motion-blur` only on things whose subtree never changes: solid shapes, static text. A widget flies as an explicit static flyer (its own markup + class CSS) and the live widget takes over when it lands |
| 33 | A label that already faded out reappears for a frame, overlapped with the next one | Two tweens on the same target + property overlapped in time (an entry still running when the exit starts). Which wins depends on SEEK DIRECTION — and the shutter seeks back and forth (Servi v6, 4.96 s) | Never overlap tweens on one property. Retargets of geometry go through `MS.morph` (summed springs); opacity crossfades get windows that end before the next starts |
| 34 | Frame 0 is a blank page (QuickTime poster, platform thumbnail) | Everything enters after 0, and a `tl.set(…, 0)` does not paint on the first seek | Frame 0 is a poster: its state in CSS, and the first element already mid-spring (continuation ease from `springStep(PRE)`, same curve and velocity) |
| 35 | Rows turn muddy grey mid-transition (Servi back office v1, bandeja) | Tweening `backgroundColor` from opaque `#fff` to a low-alpha tint (`rgba(11,32,51,0.04)`) interpolates RGB and alpha together, so the midpoint is a half-opaque grey | Tween between two colours with the SAME rgb (`rgba(ink,0)` → `rgba(ink,0.04)`) once the surface behind is in place |
| 36 | A stack of cards shows the text of the cards underneath | Pushing older cards back by lowering their opacity makes them see-through | Keep them opaque and darken them with a cover layer (`.dim`, ink at 0.3 per level) inside the stack wrapper |
| 14 | Strike/caret in the wrong place | Positions guessed before the font loaded | Build the timeline in `document.fonts.ready`, measure with `offset*` (ignores transforms) |
